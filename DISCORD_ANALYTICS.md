# Discord analytics

Apply the existing profile-picture migration and `022_manager_performance_targets.sql`, then `023_discord_analytics.sql` from aether-site before enabling manager reports. Existing Supabase bot service credentials are reused; browser users cannot call the Discord RPCs.

Configure the destination with `/set-automation-channel purpose:manager-performance channel:<channel>`. Configure monthly agency and manager diamond targets in the website Admin Performance Targets panel. Reports update after successful website synchronization and pick up target changes on subsequent sync cycles. Report pages have stable persisted message keys; restarts and uncertain sends reuse the durable publisher. Manual/non-auto imports do not publish manager summaries. Monthly totals use one exact month-to-date website import. Missing roster coverage is unavailable rather than a partial total. Contribution is unavailable when agency diamonds are zero.

Manager reports attach an AETHER Manager Summary PNG leaderboard, with separate daily and month-to-date rankings. Each manager combines all assigned creators. The header shows agency diamonds, configured target and progress. Daily columns show diamonds, creators who went LIVE, valid days and active rate (creators with a valid LIVE day / assigned team size). Monthly columns show diamonds, agency share, creator count and combined valid days. Daily values use adjacent report snapshots or month day one. Zero month-to-date metrics prove zero activity even when a newly reported creator lacks a baseline. Metrics are checked independently, so missing LIVE hours do not hide known diamonds. A + on the LIVE count marks a verified minimum when an activity baseline is missing. The report date is explicit rather than assuming yesterday. Reports paginate after ten managers and update the existing automated messages. No Excel export is attached.

The leaderboard retains the top 15 and full imported roster totals, with a new navy/blue/purple image. Stats now include a compact three-date daily diamonds image. Cumulative month-to-date snapshots require an adjacent previous date to establish daily diamonds, except the first of a month. Missing baselines, corrections and conflicting snapshots are unavailable; a verified unchanged snapshot is zero.

Avatars first reuse approved website profile pictures through freshly signed private storage requests. Cached images refresh after 24 hours and profile revisions refresh after changes. URLs and service credentials are never persisted in the revision manifest. Removed or disabled profiles clear the website image cache. TikTok fallback now resolves the creator handle instead of a numeric ID; missing images retain the existing initials fallback.

Run `python -m unittest discover -s tests`. Tests use fake Discord channels and exercise report restarts, persistent message updates, graph baselines/zero/corrections, avatar expiry/cache/removal and existing import/schedule behavior. Live Discord delivery requires the configured bot and channel permissions; local tests do not claim deployment.

## Daily manager delivery

The automated Manager Summary is sent to Discord text channel `1554887728183640158` after each daily report is imported and successfully synced to the website, like creator stats. Each daily summary shows month-to-date combined creator totals, monthly target and progress, plus the daily performance section. It does not wait for month-end. A 30-second retry worker handles delayed sync and restarts. Daily delivery is persisted; retries reuse the same date's message, existing daily posts stay unchanged, and later dates create new messages preserving previous daily summaries. The bot uses the latest imported report rather than replaying old reports on startup.

Vex (Administrator or Bot Controller role) can run `/set-team-target amount:1354619 month:2026-10`. The month defaults to the current UK month. Targets persist per month and override the website agency target; actual diamonds remain calculated from creator reports. Restart/deploy the bot to register the command and activate delivery.

`/manager-summary` sends a fresh image on every manual request. Automatic delivery posts a separate image per report date and preserves previous posts, including on retries and restarts.

Manager Summary artwork now follows the supplied TEAM VEXTAL reference: fixed 1024x1536 composition for up to five managers, matching header/card/table coordinates, portable bundled Barlow typography, gradient outlines and icons, and a percentage-filled progress bar. It retains the reference proportions for smaller teams without inventing manager rows. Larger teams expand or paginate. The font license files ship with the renderer. LIVE-history qualifiers are shown in the Discord message rather than adding an unreferenced footer to the artwork.
